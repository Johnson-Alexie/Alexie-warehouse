1.随机数

- 猜数字程序每次运行时，正确答案永远相同

- rand() 是伪随机数生成器，程序启动时默认种子固定（glibc下通常为1）

- 报错 `cast from 'int*' to 'int' loses precision`

- 64位系统里指针是8字节，int 只有4字节，(int)arr 把地址硬塞进 int 会截断精度

## 知识点

1.const

- `const int * p = &a` ：常量指针，可更改值，不能更改地址
- ` int * const p = &a` ：指针常量，可更改地址，不能更改值
- `const int * const p = &a` ：都不能更改

## 计算机视觉基础概念

### 图像的表示

1.像素

- 像素是图像的最小单位，记录图像的颜色和亮度信息。

2.分辨率

- 图像的像素总数，通常表示为 宽 × 高 （如 1920×1080）。分辨率越高，图像细节越丰富，但占用的存储和计算量也越大。

3.通道数

- 表示每个像素用几个数值表示。
- 单通道：1个数值，即灰度图。
- 三通道：R,G,B3个数值，即彩色图。

- 四通道 ：在 RGB 基础上增加 Alpha 透明度通道

4.位深

- 指单个通道每个数值用多少位二进制存储。

- 8 位 ：0～255，最常用。
- 16 位 ：0～65535，用于高精度图像（如深度图、工业相机）。
- 32 位浮点 ：用于科学计算。

5.灰度图与彩色图的存储差异

- 灰度图为单通道，彩色图为三通道

- 灰度图单像素占用 1 字节（8位），彩色图单像素占用 3字节（RGB 8位）
- 彩色图存储数据量大约是灰度图的三倍
